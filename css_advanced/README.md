# CSS Advanced

## Project Overview

This project is a continuation of the HTML Advanced project.

The goal is to transform the SmileSchool webpage from a basic HTML structure into a styled webpage that matches the provided Figma design.

The project focuses on using CSS to reproduce the layout, colors, typography, spacing, images, buttons, and other visual elements from the designer file.

## Project Sections

The webpage contains:

- Header and Banner
- Quote
- Popular Tutorials
- Free Membership
- FAQ
- Footer

## Technologies Used

- HTML5
- CSS3

## Learning Objectives

By completing this project, I will be able to:

- Explain what CSS is
- Add styles to HTML elements
- Understand CSS classes
- Understand CSS selectors
- Calculate CSS specificity
- Understand CSS box properties
- Understand how a browser loads a webpage

## Requirements

- All files end with a new line
- A `README.md` file is present at the root of the project
- No external libraries or frameworks are used
- The website is built using HTML and CSS
- The code should be W3C compliant
