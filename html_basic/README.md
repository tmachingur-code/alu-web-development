# HTML Basic

This project introduces the fundamentals of HTML and focuses on creating valid, well-structured webpages using HTML5.

## Learning Objectives

By completing this project, I learned how to:

* Create a basic HTML page.
* Understand HTML elements and tags.
* Use HTML attributes.
* Structure webpages using semantic HTML elements.
* Create headings and paragraphs.
* Add links and images to webpages.
* Create navigation between webpages.
* Embed a tweet in a webpage.
* Understand the basic structure of the DOM.
* Understand how a browser loads and renders an HTML webpage.
* Validate HTML documents using the W3C Validator.

## Project Files

* `base_index.html` — Basic and valid HTML5 page structure.
* `index.html` — Main webpage containing headings, paragraphs, links, and a clickable image.
* `tweets.html` — Webpage containing an embedded tweet and navigation back to the homepage.
